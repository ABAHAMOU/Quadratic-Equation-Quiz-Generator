# Quadratic Equation Quiz Generator

Application web interactive développée avec Flask permettant de générer dynamiquement des exercices sur les équations du second degré ($ax^2 + bx + c = 0$) et de vérifier les réponses des utilisateurs (discriminant $\Delta$ et nombre de solutions).

Projet réalisé par **Amine El Azri** et **Ziad Abahamou**.

## 🚀 Fonctionnalités

* **Génération probabiliste :** Simulation discrète générant des équations à discriminant négatif, nul ou positif.
* **Correction automatique :** Évaluation dynamique du discriminant $\Delta$ calculé et du nombre de solutions réelles.
* **Système de Quiz :** Choix du nombre d'exercices par session et calcul du score final.

## 🛠️ Stack Technique

* **Langage :** Python
* **Framework :** Flask
