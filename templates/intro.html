Polynômes
du second degré

Résoudre une équation quadratique, déterminer son discriminant, et interpréter ses solutions.

①

Forme générale

Une équation du second degré s'écrit sous la forme canonique suivante, où les coefficients a, b, c sont des réels et a ≠ 0 :

ax² + bx + c = 0

Les termes a, b et c sont appelés monômes. Le coefficient a est dit dominant — il ne peut jamais être nul.

②

Le discriminant

Le nombre de solutions de l'équation est entièrement déterminé par le signe du discriminant Δ :

Δ = b² − 4ac
Δ < 0
0
solution réelle

L'équation n'admet aucune solution dans ℝ.

Δ = 0
1
solution double
x₀ = −b / 2a
Δ > 0
2
solutions distinctes
x = (−b ± √Δ) / 2a
